# Open Annihilation language packs

The sources of Open Annihilation's downloadable language packs (`.oalang`), starting with Simplified Chinese. Each pack is built and checked with this repository's own scripts, and published through Open Annihilation's content library; every pack and revision is also a GitHub release here.

The five languages Total Annihilation 3.1c ships with (English, German, Spanish, French and Italian) need no pack: Open Annihilation reads them from the game's own data.
