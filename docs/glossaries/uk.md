# Ukrainian (uk) glossary: Keys

The rest of the voice is the pack's own: infinitives on buttons and on
confirmation questions, ти in an instruction (`натисни`, `утримуй`), «quotes»,
and the apostrophe ʼ (U+02BC). This section is the one term for each key idea.

| English | Ukrainian |
|---|---|
| key layout | розкладка клавіш |
| key editor | редактор клавіш |
| action (a binding; also where English still says "command" for one) | дія |
| changes of your own | власні зміни |
| clash | конфлікт |
| latch / latched | закріпити / закріплено |
| latchable (the filter) | Закріпити |
| unbound (the filter) | Порожньо |
| letter (of a key) | літера |
| place (of a key) | позиція |
| hold to confirm | Утримувати для підтвердження |

Named keys stay Latin where the keyboard prints them: Shift, Ctrl, Alt, Esc,
Escape, Enter, Tab, Space, Backspace, Delete, Insert, Home, End, Page Up,
Page Down, F1–F12, Win. In a sentence, Space is `пробіл`. Arrows are
`Стрілка вгору`, `Стрілка вниз`, `Стрілка вліво`, `Стрілка вправо`. Numpad
is `Цифровий блок`. Mouse buttons: `Ліва кнопка`, `Права кнопка`,
`Середня кнопка`. Wheel: `Коліщатко вгору`, `Коліщатко вниз`.
