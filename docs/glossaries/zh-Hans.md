# Simplified Chinese (zh-Hans) glossary: Keys

The rest of the voice is the pack's own: 你 for the player, 请 on an
instruction, 吗？ on a question, and the words the pack already uses
(模组, 资源库, 设置, 回滚, 指挥官, 单位). 命令 stays the unit order.
A key-binding action is 动作, not 命令.

| English | Chinese |
|---|---|
| key layout | 按键布局 |
| key editor | 按键编辑器 |
| action (a binding; also where English still says "command" for one) | 动作 |
| changes of your own | 自己的更改 |
| clash | 冲突 |
| latch / latched | 锁定 / 已锁定 |
| letter (of a key) | 字母 |
| place (of a key) | 位置 |
| hold to confirm | 按住以确认 |

Named keys. Shift, Ctrl, Alt, Esc, Escape, Tab, Enter, F1–F12, Delete, Home,
End, Page Up, Page Down and Win stay Latin, as the keyboard prints them.

| English | Chinese |
|---|---|
| Space | 空格 |
| Backspace | 退格 |
| Arrow up / down / left / right | 上箭头 / 下箭头 / 左箭头 / 右箭头 |
| Numpad | 小键盘 |
| Left / Right / Middle button | 左键 / 右键 / 中键 |
| Wheel up / down | 滚轮向上 / 滚轮向下 |
